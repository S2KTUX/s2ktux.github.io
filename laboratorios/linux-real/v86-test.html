Notas

Es Debian, no Red Hat: algunos servicios y rutas cambian. DNF trabaja con RPM locales de prácticas; APT administra Debian.

La recuperación de root y el reetiquetado pueden tardar aproximadamente 5–10 minutos, o más según el equipo.

El guardado es manual y solo se conserva en este navegador. Reset devuelve esta máquina a su estado inicial; no toca los archivos del ordenador.

Más opciones

Actívalo antes de iniciar. Usa el puente público wisp.mercurywork.shop para TCP y Cloudflare para DNS; no envíes credenciales ni datos privados. No admite ping/UDP externos y bloquea los destinos privados. Para configurar Linux: IP 10.42.0.20/24 (máquina 2: 10.42.0.11/24), gateway y DNS 10.42.0.1. El servicio externo puede fallar.
