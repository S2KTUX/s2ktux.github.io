Sobre el laboratorio

La terminal ejecuta Alpine Linux, Docker Engine y Compose reales dentro de una máquina emulada en el navegador. No interpreta tus comandos para inventar respuestas. Usa una CPU y 1 GiB de memoria; las imágenes tienen que ser compatibles con linux/386.

Las imágenes preparadas son Alpine, BusyBox, s2ktux/nginx-lab:2, s2ktux/postgres-lab:17, s2ktux/go-lab:ligero y s2ktux/registry-lab:2. Las cuatro últimas son adaptaciones abiertas para las prácticas, no las imágenes oficiales con otra etiqueta. Nginx y PostgreSQL son servicios reales; Go compila de verdad. La construcción clásica de Docker está activada por defecto para reducir la espera.

Guardar máquina conserva el Linux, sus archivos, contenedores y volúmenes en este navegador. Vuelve al prompt antes de guardar. No hay guardado automático y el navegador puede eliminar datos si necesita espacio. Reset borra solamente el guardado de Docker y carga otra vez la fábrica; no borra el laboratorio Linux ni Kubernetes.

Internet está integrado en la red de Linux mediante un puente público. Puede observar tráfico sin cifrar: utiliza solo datos de prácticas. No se aceptan conexiones entrantes de Internet ni acceso a redes privadas del portátil. Los puertos publicados pertenecen a la máquina emulada: prueba las webs con curl desde la terminal, no con localhost del portátil. Las descargas grandes y las construcciones pueden tardar más que en un ordenador nativo.

Este laboratorio cubre prácticas de las tres clases de Docker. No es una máquina x64, no sustituye un clúster CKA ni promete ejecutar cualquier imagen o reproducir la velocidad de un servidor. Las funciones que use Docker se ejecutan realmente en Linux, con los límites del hardware emulado.

Software libre

Motor v86 (BSD), xterm (MIT), BIOS SeaBIOS/VGABIOS y paquetes oficiales de Alpine, con sus licencias originales. Las fuentes exactas de Alpine y del kernel, los parches y las recetas se entregan aparte para no ocupar GitHub Pages. Los avisos y fuentes del motor reutilizado están en el laboratorio Linux.
