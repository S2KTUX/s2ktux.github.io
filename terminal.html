💡 Escribe man <comando> en la terminal para ver todas sus opciones. Aquí solo va el comando y para qué sirve.
pwd · cd · lsRuta actual, cambiar de directorio, listar.
tree · cat · head · tailÁrbol, ver contenido, principio/final.
mkdir · rmdir · touchCrear directorio / borrar vacío / crear fichero.
rm · cp · mv · lnBorrar, copiar, mover, enlazar.
find · grep · wcBuscar ficheros / texto / contar.
stat · file · whichMetadatos / tipo / ruta del ejecutable.
sort · uniq · nlOrdenar / quitar duplicados / numerar.
echo texto > f · >>Escribir en fichero (sobrescribe / añade).
cmd1 | cmd2Tuberías: encadena la salida de un comando a otro.
cmd1 && cmd2 · || · ;Encadena por éxito / fallo / siempre.
vi FICHERO · nano FICHEROEditores (vi modal; nano con ^O/^X).
./script.shEjecuta un script con permiso +x.
ls -lLee permisos: rwx para usuario/grupo/otros. Ej: -rwxr-x--- = 750.
chmod 640 F · chmod u+x FOctal (r=4 w=2 x=1) o simbólico (u/g/o + +/- + rwx). Ej: 640 = rw-r-----.
chmod -R g+w DIR-R aplica recursivamente a todo el árbol.
chown usuario:grupo FCambia propietario y grupo (chgrp solo el grupo).
umaskMáscara por defecto (022 → ficheros 644, directorios 755).
chmod u+s · g+s · +tEspeciales: SUID / SGID (herencia de grupo en dirs) / sticky bit.
getfacl FMuestra las ACL de un fichero (permisos más allá de ugo).
setfacl -m u:ana:rwx FDa permisos a un usuario concreto (-m modifica, -x quita, -b borra todas).
whoami · id · groupsQuién soy, UID/GID, grupos.
useradd · userdel · usermodCrear / borrar / modificar usuarios.
groupadd · passwd · chageCrear grupo / contraseña / caducidad.
su · exit · getentCambiar de usuario / volver / consultar BD.
ps · top · pgrep · killVer procesos / en vivo / buscar / matar.
systemctlServicios: status/start/stop/enable/restart.
journalctlLogs de servicios y del sistema.
crontab · uptime · freeTareas programadas / carga / memoria.
dnf search TEXTO · dnf info PAQBusca en los repos y muestra detalles de un paquete.
dnf install PAQ · -yInstala (pide confirmación; -y la salta). Ej: dnf install httpd.
dnf remove · dnf updateElimina o actualiza todo el sistema.
dnf list installed · availableLista paquetes instalados o disponibles.
dnf provides /ruta · repolistQué paquete da un fichero · repos activos.
dnf config-manager --add-repo URLAñade un repositorio en /etc/yum.repos.d/.
dnf group list · group installGrupos de paquetes (p.ej. "Development Tools").
rpm -qa · rpm -q PAQLista todo lo instalado · consulta un paquete.
rpm -ql PAQ · rpm -qf /rutaFicheros de un paquete · a qué paquete pertenece un fichero.
rpm -qi PAQ · rpm -V PAQInformación detallada · verifica integridad.
rpm -ivh FICHERO.rpmInstala un .rpm local (para RHCSA; dnf resuelve dependencias).
yumObsoleto en RHEL 9: usa dnf (apt/dpkg no existen en Red Hat).
lsblk · fdisk · blkidDiscos, particiones y UUIDs. Hay un /dev/sdb vacío.
partedParticionado (también discos grandes / GPT).
mkfs.xfs · mkfs.ext4Formatea una partición.
mount · umount · df · duMonta / desmonta / uso de disco.
pvcreate · vgcreate · vgextendLVM: inicia PV, crea/amplía el grupo (VG). Compruébalo con pvs / vgs.
lvcreate -n x -L 5G vgCrea un volumen lógico (· -l 100%FREE usa todo el espacio libre).
lvextend -r -L +2G /dev/vg/xAmplía el LV y, con -r, también el FS (o xfs_growfs / resize2fs).
pvs vgs lvs · lvremoveVer PV/VG/LV · eliminar un volumen.
mkswap · swapon --showCrear y activar/ver el swap.
ip a · ip routeDirecciones IP e interfaces · tabla de rutas (puerta de enlace).
ip link set eth0 up|downActiva o desactiva el enlace (equivale a ifup/ifdown).
nmcli general · dev statusEstado de red y de los dispositivos (connected/disconnected).
nmcli con show [eth0]Lista conexiones · detalle completo de una (IP, gateway, DNS).
nmcli con mod eth0 ipv4.method manualFija IP estática (método manual).
... ipv4.addresses 10.0.0.5/24Dirección y máscara. Añade ipv4.gateway y ipv4.dns.
nmcli con up eth0Aplica los cambios (obligatorio tras con mod).
nmtuiConfiguración de red por menús (editar/activar/hostname).
ping 8.8.8.8 · ping HOSTPrueba conectividad. Falla si falta enlace, gateway o DNS.
ss -tlnpPuertos TCP en escucha y el proceso que los abre.
firewall-cmd --list-allFirewalld: servicios/puertos. --add-* --permanent y --reload.
hostnamectl set-hostname NOMBREFija el nombre del sistema de forma persistente.
getenforce · sestatusModo actual / estado de SELinux.
setenforce 0|1Permissive / Enforcing.
getsebool · setseboolVer / cambiar booleanos.
semanage · restorecon · chconPuertos, contextos y su restauración.
ls -Z · ls -lZContexto SELinux de los ficheros (· -lZ en formato largo).
restorecon -Rv RUTARestaura el contexto correcto (p.ej. tras tocar /etc/shadow en rescate).
touch /.autorelabelFuerza el reetiquetado de todo el FS en el próximo arranque.
Flujo inicial del motor Docker: instalación, daemon, diagnóstico y primera ejecución. Este cheatsheet no mezcla objetivos RHCSA.
dnf -y install dnf-plugins-coreInstala el complemento necesario para gestionar repositorios.
dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repoAñade el repositorio estable oficial de Docker CE.
dnf install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-pluginInstalación completa mediante el gestor de paquetes.
curl -fsSL https://get.docker.com | shScript rápido de conveniencia; Docker recomienda el repositorio para un host estable.
systemctl enable --now dockerArranca el daemon ahora y en los siguientes reinicios.
systemctl status dockerEstado realista del daemon de Docker.
docker version · docker infoComprueba cliente, servidor, almacenamiento y estado.
docker run hello-worldVerificación completa: pull, create, start y salida.
journalctl -u dockerLogs de arranque y errores del daemon.
/etc/docker/daemon.jsonConfiguración persistente del daemon: logs, storage y registries.
docker search TERM · docker pull IMGBusca y descarga imágenes desde un registry.
docker images · image lsLista repositorio, tag, ID y tamaño local.
docker inspect IMG · history IMGMetadatos completos y capas de construcción.
docker build -t miapp:v1 .Construye una imagen desde el Dockerfile del contexto actual.
docker build --no-cache -t IMG .Reconstruye todas las capas sin reutilizar caché.
docker tag ORIG usuario/app:v1Añade una referencia lista para publicar.
docker login · docker push IMGAutenticación y publicación en el registry.
docker save -o img.tar IMG · load -i img.tarExporta e importa imágenes sin registry.
docker rmi IMG · image pruneElimina imágenes concretas o capas sin uso.
docker run · ps · logsArranca contenedores, lista, logs.
docker run -d --name web -p 8080:80 nginxNombre, segundo plano y publicación de puertos.
start · stop · restart · rmCiclo de vida de un contenedor.
exec · attach · inspect · topEntrar, detalles y procesos.
docker logs -f --tail 100 CONTSigue logs y limita las líneas iniciales.
docker exec -it CONT shEjecuta una shell dentro de un contenedor activo.
docker cp CONT:/ruta ./destinoCopia ficheros entre contenedor y host.
docker create · start -aSepara la creación del arranque y adjunta la salida.
run -m --cpus --restartLímites de recursos y política de reinicio.
docker stats · docker top CONTCPU, memoria, red, bloque y procesos del contenedor.
docker volume create · ls · inspectVolúmenes persistentes administrados por Docker.
docker run -v datos:/ruta IMGMonta un volumen con nombre dentro del contenedor.
docker run -v /host:/contenedor IMGBind mount desde un directorio del host.
docker cp ORIGEN DESTINOCopia ficheros entre host y contenedor.
docker volume rm · volume pruneBorra volúmenes concretos o los que no están en uso.
--mount type=volume,src=datos,dst=/dataSintaxis explícita recomendada para montajes complejos.
docker network create · ls · inspectRedes bridge propias con DNS entre contenedores.
docker run --network labnet --name api IMGInicia el contenedor directamente en una red propia.
docker network connect · disconnectConecta o retira un contenedor de una red.
bridge · host · noneDrivers integrados: NAT aislado, pila del host o sin red.
-p 127.0.0.1:8080:80Publica un puerto solo en la interfaz local.
docker port CONTMuestra los mapeos de puertos efectivos.
docker network rm · network pruneLimpia redes propias sin contenedores conectados.
docker compose up -d · downArranca / para toda la app multi-contenedor.
docker compose ps · logs -fEstado de servicios y logs agregados.
docker compose build · pullConstruye servicios propios o actualiza imágenes.
docker compose up -d --scale web=3Escala un servicio durante el despliegue.
docker compose exec web shEjecuta un comando dentro de un servicio.
docker compose down -vElimina contenedores, red y volúmenes del proyecto.

docker stats · docker eventsMétricas en vivo y eventos del daemon.
docker system dfEspacio usado por imágenes, contenedores y volúmenes.

man · helpManual de un comando / índice rápido.

El clúster responde a comandos y conserva sus recursos. Usa kubectl explain y --help como en una máquina real.
kubectl cluster-infoInfo del control plane.
kubectl get nodes -o wideNodos del clúster y su estado.
kubectl get pods -ATodos los pods, todos los namespaces.
kubectl describe pod NOMBREDetalle completo + eventos.
kubectl explain pod.specDocumentación de un campo del API.
kubectl config get-contexts / use-contextVer y cambiar de clúster/contexto.
kubectl api-resources · api-versionsRecursos disponibles, nombres cortos, grupos y versiones.
kubectl get RESOURCE -o yaml|jsonInspección declarativa completa del objeto.
-n NS · -A · --context CONTEXTOÁmbito de namespace, todos los namespaces o contexto concreto.
kubectl run NOMBRE --image=IMGPod suelto (debug rápido).
kubectl create deployment NOMBRE --image=IMGDeployment con su ReplicaSet.
kubectl scale deployment NOMBRE --replicas=NEscalar réplicas.
kubectl rollout status/history/undo deployment NOMBREEstado, historial y rollback.
kubectl apply -f fichero.yamlAplica el estado declarado (YAML).
kubectl edit deployment NOMBREEdita el recurso en caliente.
kubectl delete -f fichero.yamlElimina lo declarado en el fichero.
kubectl set image deploy/app c=IMGActualiza la imagen de un contenedor del Deployment.
kubectl rollout restart deploy/appFuerza un nuevo rollout sin cambiar la plantilla funcional.
kubectl create job · create cronjobTrabajo finito o ejecución programada.
kubectl autoscale deploymentCrea un HPA basado en métricas.
kubectl create configmap N --from-literal=k=vConfiguración no sensible.
kubectl create secret generic N --from-literal=k=vConfiguración sensible (base64, no cifrado).
envFrom / valueFrom.configMapKeyRefInyectar como variables de entorno del Pod.
volumeMounts + configMap/secret como volumenInyectar como ficheros dentro del contenedor.
kubectl get secret N -o jsonpath='{.data.k}' | base64 -dLeer el valor real de un secret.
kubectl create configmap N --from-file=RUTAConstruye un ConfigMap desde uno o varios ficheros.
command / args / envSobrescribe ENTRYPOINT, CMD y variables del contenedor.
livenessProbe · readinessProbe · startupProbeSalud, disponibilidad para tráfico y arranque lento.
securityContextUsuario, grupo, privilegios y capacidades del Pod/contenedor.
resources.requests / resources.limitsReserva mínima y techo de CPU/memoria por contenedor.
kubectl describe node NODOCapacidad del nodo y lo ya reservado.
nodeSelector: disktype: ssdFuerza el pod a nodos con esa etiqueta.
affinity / anti-affinityReglas finas de "cerca de" / "lejos de" otros pods o nodos.
kubectl taint NODO clave=valor:EffectEl nodo repele pods salvo que los toleren.
tolerationsPermite a un pod aceptar un taint concreto.
kubectl cordon/drain/uncordon NODOSacar un nodo de servicio para mantenimiento.
priorityClassName · preemptionPolicyPrioridad y posible desalojo de Pods menos importantes.
topologySpreadConstraintsDistribuye réplicas entre zonas, hosts u otros dominios.
kubectl top nodes · top podsConsumo actual para decisiones de scheduling.
PersistentVolume (PV)Almacenamiento real, lo provee el clúster/admin.
PersistentVolumeClaim (PVC)Petición de almacenamiento que hace una app.
StorageClassPlantilla para aprovisionar PVs de forma dinámica.
kubectl get pv,pvcVer volúmenes y sus peticiones.
accessModes: RWO / ROX / RWXCómo se puede montar (uno, varios en lectura, varios en escritura).
reclaimPolicy: Delete|RetainQué ocurre con el volumen cuando se elimina el claim.
volumeMode: Filesystem|BlockEntrega un sistema de ficheros o un dispositivo de bloque crudo.
kubectl describe pvc NOMBREDiagnostica Pending, clase, eventos y binding.
