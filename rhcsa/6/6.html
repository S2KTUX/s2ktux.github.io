1. Crear, montar y desmontar sistemas de archivos locales

Linux soporta distintos sistemas de archivos. Como vimos en la clase anterior, los más comunes son ext4, xfs y vfat.

  • ext4 → Sistema estándar en Linux.
  • xfs → Optimizado para grandes volúmenes (no permite reducción).
  • vfat → Compatible con otros sistemas operativos, común en USB.

Para crear un sistema de archivos utilizamos mkfs según el tipo. En el ejemplo creamos dos particiones nuevas, una en ext4 y otra en xfs, y posteriormente las montamos.

Una vez formateado y montado, podemos hacerlo permanente añadiéndolo a /etc/fstaby para desmontar usamos umount.

2. Montar y desmontar sistemas de archivos de red usando NFS

NFS permite montar directorios remotos como si fueran locales. Es muy común en entornos empresariales y es un objetivo típico del examen RHCSA.

Puede pedirse de dos formas:

  • Configuración cliente-servidor real.
  • Configuración completamente local.

Configuración en el SERVER: instalar NFS, crear directorio compartido, asignar permisos, configurar /etc/exports y abrir firewall.

Configuración en el CLIENTE: instalar cliente NFS, crear punto de montaje y montar manualmente o mediante /etc/fstab.

  • exportfs -au y luego exportfs -ar
  • umount -f /mnt/nfs

4. Ampliar volúmenes lógicos existentes

Este punto continúa lo aprendido en la clase 5. Para ampliar almacenamiento sin pérdida de datos usamos lvextend.

Cosas importantes a recordar :

  • Usar -r para ampliar filesystem automáticamente.
  • Si no se usa, ejecutar después xfs_growfs o resize2fs.
  • XFS solo permite ampliar, nunca reducir.

5. Diagnosticar y corregir problemas de permisos

Muchos errores en Linux están relacionados con permisos incorrectos. Podemos analizarlos usando ls -l

Ya sabemos que los permisos se dividen en lectura (r), escritura (w) y ejecución (x) para usuario - grupo - otros

Permisos especiales:

  • SUID (4) → Ejecuta con permisos del dueño.
  • SGID (2) → Ejecuta o crea archivos con permisos del grupo.
  • Sticky Bit (1) → Solo el dueño puede borrar archivos.

Para saber que tenemos los permisos especiales activos, simplemente veremos una s en SUID o SGID y una t en sticky bit
